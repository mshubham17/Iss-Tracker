# ISS Tracker

An interactive 3D visualization of the International Space Station (ISS), tracking its real-time position as it orbits Earth.

## Overview

The project visualizes the International Space Station orbiting Earth in real time. Users can interact with a 3D globe, follow the ISS, explore its orbital trajectory, and monitor live satellite telemetry.

The globe also represents Earth's day and night cycle using the Sun's position, providing a more realistic view of the planet.
## Tech Stack

- JavaScript
- Node.js
- npm
- Vite
- 3D rendering and visualization
- HTML5
- CSS3

## APIs

The project uses publicly accessible APIs to retrieve satellite and geographical information.

| [Where The ISS At](https://wheretheiss.at/) | Real-time ISS position and orbital data |
| [BigDataCloud](https://www.bigdatacloud.com/) | Reverse geocoding and geographical information |

## Purpose

Because something this extraordinary deserves more than just a dot on the map.
